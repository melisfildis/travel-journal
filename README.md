🌍 About the Project

Travel Journal is a personal digital travel journal designed to help you document your journeys, save your favorite memories, and keep all your travel experiences in one place.

Whether it's a weekend getaway, a beach holiday, or a road trip across different countries, Travel Journal allows you to turn your experiences into lasting memories.

The goal is to create a beautiful and personal space where every destination has a story.

✨ Features

Travel Entries: Create, edit, and delete travel journal entries.

Destinations: Document the cities and countries you've visited.

Photo Memories: Add photos to preserve special moments.

Personal Notes: Write about your experiences, favorite places, and recommendations.

Trip Organization: Keep your travel memories organized.

Responsive Design: Access your journal on different screen sizes.

🚀 Getting Started

Installation

Clone the repository: git clone https://github.com/melisfildis/travel-journal.git

Navigate to the project directory: cd travel-journal

Install dependencies: npm install

Start the development server: npm run dev



🌍 Proje Hakkında

Travel Journal, seyahatlerini kaydetmek, en güzel anılarını saklamak ve tüm seyahat deneyimlerini tek bir yerde toplamak için tasarlanmış kişisel bir dijital seyahat günlüğüdür.

İster hafta sonu kaçamağı, ister deniz tatili, ister farklı ülkeleri kapsayan bir yolculuk olsun; Travel Journal, yaşadığın deneyimleri kalıcı anılara dönüştürmeni sağlar.

Projenin amacı, her destinasyonun kendine ait bir hikâyesinin olduğu, kişisel ve keyifli bir dijital alan oluşturmaktır.
